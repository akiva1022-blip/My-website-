# JARVIS V1

This is the first phone-first Jarvis interface.

## Run
Open `index.html` in a browser, or serve this folder with any static web server.

## Current features
- Jarvis-style interface
- Responsive mobile layout
- Local conversation memory
- Browser speech-to-text where supported
- Quick command buttons

## Next build
Connect an AI API through a small backend. Never put a private API key directly into `app.js` in a public deployment. Then add persistent memory, tasks/reminders, web research, calendar/email, and controlled actions.
